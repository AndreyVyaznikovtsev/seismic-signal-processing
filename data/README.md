# Данные

**Файлы данных в git не хранятся.** В репозитории только этот файл.

## Почему

Git хранит полную историю каждого файла. Двоичные данные не сжимаются
дельтами, поэтому репозиторий распухает необратимо: удалить файл из
истории позже можно только переписав её у всех.

Это общее правило научного программирования, а не особенность проекта.

## Как получить данные

Данные раздаются отдельно. Положите их в этот каталог, сохранив имена,
и проверьте контрольные суммы:

```bash
sha256sum -c checksums.txt
```

## Как ссылаться на данные из кода

Путь берётся из переменной окружения, а не зашивается в код:

```python
import os
from pathlib import Path

DATA = Path(os.environ.get("SEISDSP_DATA", "data"))
trace = np.load(DATA / "line01.npy")
```

Так примеры работают и у того, кто держит данные в другом месте.
