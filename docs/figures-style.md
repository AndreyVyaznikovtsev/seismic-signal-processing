# Гайд по рисункам

Рисунок в учебнике — не украшение, а аргумент. Он должен читаться
отдельно от текста.

## Обязательное

1. **Подписаны обе оси, с единицами.** «время, с», «частота, Гц»,
   «отсчёт $n$». Не «t» и не пусто.
2. **Подпись называет рисунок.** «Зависимость амплитуды от расстояния»,
   «Спектр трассы после полосовой фильтрации». Вывод из рисунка —
   что амплитуда падает вдвое за первые 200 м — принадлежит основному
   тексту, а не подписи.
3. **Читается при ширине 8 см.** Шрифт не мельче 8 пт, линии не тоньше
   0,8 пт. Уменьшите рисунок до ширины колонки и посмотрите сами.
4. **Генерируется кодом при сборке.** Картинки файлами не коммитятся:
   иначе рисунок разойдётся с данными и никто этого не заметит.
5. **Зерно генератора зафиксировано,** если есть случайность.

## Рекомендуемое

* сетка `alpha=0.3` — помогает считывать значения, не споря с данными;
* `fig.tight_layout()` — иначе подписи обрезаются;
* дискретные сигналы рисуются `stem`, а не `plot`: ломаная между
  отсчётами — это уже интерполяция, то есть другой объект;
* для нескольких кривых — разный тип линии, а не только цвет
  (печать бывает чёрно-белой);
* соотношение сторон ближе к `(6, 2.6)` для временных рядов.

## Заготовка

````markdown
```{python}
#| label: fig-example
#| fig-cap: "Наименование рисунка"
import matplotlib.pyplot as plt
import numpy as np

fig, ax = plt.subplots(figsize=(6, 2.6))
ax.plot(t, x, lw=0.9)
ax.set_xlabel("время, с")
ax.set_ylabel("амплитуда, отн. ед.")
ax.grid(alpha=0.3)
fig.tight_layout()
```
````

Метка `fig-` обязательна: по ней работают перекрёстные ссылки
вида `@fig-example`.

## Чего не делать

* заголовок внутри рисунка (`ax.set_title`), дублирующий подпись;
* цветовая шкала `jet` — она искажает восприятие градиентов,
  берите `viridis`;
* три кривые одного цвета;
* разрешение по умолчанию для растровых вставок — ставьте `dpi=150`.
